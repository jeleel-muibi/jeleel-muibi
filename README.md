I build governed infrastructure systems across cloud and on-premises environments, with a focus on source-of-truth operations, controlled execution, networking, recovery, and operational handover.

I created [HybridOps](https://hybridops.tech), an open-source contract runtime that turns declared platform intent into validated operations. Its modules and blueprints combine preflight checks, ordered execution, health validation, run records, recovery controls, and teardown across shared infrastructure workflows.
