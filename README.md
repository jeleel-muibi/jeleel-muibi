# Jeleel Muibi

Founder & Infrastructure Engineer at [HybridOps Technologies](https://hybridops.tech) and creator of [HybridOps](https://github.com/hybridops-tech/hybridops-core).

I design governed infrastructure systems across data-centre and cloud environments, with a focus on authority, readiness validation, network engineering, recovery and lifecycle control.

HybridOps is an open-source contract runtime that turns declared infrastructure intent into validated operations. Its core runtime coordinates preflight checks, ordered execution, health validation, recovery decisions and reviewable run records across networking, Kubernetes, identity, databases, observability, backup and recovery.

## Open-source engineering

I publish Terraform modules and Ansible collections through GitHub, [Terraform Registry](https://registry.terraform.io/modules/hybridops-tech/sdn/proxmox/latest) and [Ansible Galaxy](https://galaxy.ansible.com/ui/namespaces/hybridops/).

My accepted upstream work spans VyOS runtime, VyOS cloud-init and documentation, NetBox Ansible, community.proxmox and Geerling Docker, and I hold the [VyOS Contributor 2026](https://www.credly.com/badges/dfd15f22-24c1-4780-a92d-db7ca0040270) credential.
